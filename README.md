# GPS Tracker — один передавач, спільне посилання для перегляду

## Як це працює
- Перший браузер, який відкриває сторінку без `?room=...`, створює приватний за випадковим ID трекер і стає власником-передавачем.
- На пристрої-передавачі потрібно натиснути **Почати передачу** та дозволити доступ до геолокації.
- Посилання на цій сторінці можна скопіювати й надіслати глядачам.
- Відкриття того самого посилання на іншому пристрої показує координати, які надходять у Firebase Realtime Database.
- Лише власник, який створив трекер, може записувати координати. Перегляд доступний кожному, хто має повне посилання.

## 1. Створи Firebase-проєкт
1. Перейди на https://console.firebase.google.com/ і створи проєкт.
2. У налаштуваннях проєкту додай Web App (іконка `</>`).
3. Скопіюй конфігурацію Firebase.
4. У `index.html` заміни значення `firebaseConfig` на свої (`apiKey`, `authDomain`, `databaseURL`, `projectId`, `appId`).
5. У Firebase Console відкрий **Authentication → Sign-in method** і ввімкни **Anonymous**.
6. Відкрий **Realtime Database → Create Database**. Скопіюй URL бази в поле `databaseURL` у конфігурації.
7. У Realtime Database → **Rules** встав вміст `database.rules.json` і натисни Publish.

> Правила дозволяють читати координати без входу — це необхідно для перегляду за спільним посиланням. Запис дозволено лише анонімному користувачу, який створив конкретний трекер. Не публікуй посилання відкрито: кожен, хто його має, може бачити поточні координати.

## 2. Опублікуй сайт через HTTPS
Найпростіше:
1. Створи репозиторій GitHub і завантаж у нього `index.html`.
2. У Settings → Pages увімкни GitHub Pages (Deploy from a branch, `main`, `/root`).
3. Дочекайся публікації сайту. Або скористайся Netlify Drop: https://app.netlify.com/drop
4. Відкрий адресу сайту на телефоні.

## 3. Запуск
1. Відкрий сайт на телефоні, який буде передавати координати.
2. Скопіюй посилання з блоку «Посилання для перегляду».
3. Натисни «Почати передачу» і дозволь геолокацію.
4. Надішли скопійоване посилання глядачеві.
5. Глядач відкриває його — карта та координати оновлюються автоматично.

## Важливі обмеження
- Геолокація працює лише в secure context: HTTPS або localhost.
- Браузер має отримати явний дозвіл користувача.
- Мобільні браузери можуть призупиняти геолокацію у фоновому режимі, після блокування екрана або закриття вкладки. Це вебсторінка, а не фоновий системний GPS-сервіс.
- Оновлення надходять тоді, коли пристрій передавача отримує нові координати; частота залежить від GPS, ОС і браузера.
- Для припинення передачі натисни «Зупинити» або закрий вкладку.
- Для завершення доступу відклич/видали відповідний запис `trackers/<roomId>` у Firebase Console. Не використовуй відкриті правила `.read: true` для чутливих даних.
